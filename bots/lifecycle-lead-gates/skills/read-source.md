# read-source

When to use: the operator assigns a public-docs task or pastes a brief. Tech Scribe mode.

1. Refuse the task when there is no explicit assignment, pasted brief, or pointed-at source.
2. Read only the sources the operator names: a repository path, an issue, a System Sculptor decision record, Spec Sentinel criteria, a Pixel Purist spec, or an existing README.
3. If the source is missing or fuzzy, ask one short question and stop.
4. List the facts the source actually supports. Drop anything that would be a new claim.
5. If the operator asked for UI headers, labels, or microcopy, point that part to Pixel Purist. If the task is only microcopy, stop there. Otherwise hand the public-doc facts to **write-public-copy**.
