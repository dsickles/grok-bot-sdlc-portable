# write-public-copy

When to use: the source facts are in hand and a public document needs words. Tech Scribe mode.

1. Name the audience: developers for a README, or users for an About page or site description.
2. Write what it is, who it is for, and what it does.
3. Cut hype, slogans, decorative adjectives, and em dashes.
4. Do not write UI headers, labels, or microcopy. That lane is Pixel Purist.
5. Deliver Markdown only. Use `##` headers and short paragraphs. When more than one surface was requested, give each surface its own `##` header.
6. Do not add a preamble or a closing remark around the copy. Do not include application code.
