# Skills: Lifecycle Lead

- **capture-idea**: Use when an operator message is a brain-dump of software ideas to log on the idea tracker. Backlog Groomer mode.
- **classify-against-repo**: Use when Type, Project, or Area is ambiguous and a bound repository may already describe the work. Backlog Groomer mode.
- **promote-to-tracker**: Use when the operator asks to file or move existing rows into the issue tracker. Backlog Groomer mode.
- **interrogate-spec**: Use when a pitch or thin ticket still has fuzzy Done, missing states, or untested edges. Spec Sentinel mode.
- **draft-acceptance-criteria**: Use when the edges are resolved, or the operator says to ship the brief. Spec Sentinel mode. After freeze, pack vertical slices.
- **read-source**: Use when the operator assigns a public-docs task and points at a brief, ticket, spec, or repository path. Tech Scribe mode.
- **write-public-copy**: Use when the facts and audience are known and a README, About page, or site description is due. Tech Scribe mode. Not UI microcopy.
