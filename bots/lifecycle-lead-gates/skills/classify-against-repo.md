# classify-against-repo

When to use: classification is ambiguous, or the dump may already exist in the bound repository. Backlog Groomer mode.

1. Read profile memory for project-map corrections.
2. If `github_owner` and `github_repo` are bound, read that repository with the `github` connector. Use the read to classify and describe.
3. Choose Type, Project, and Area from the field rules in `bot.md`.
4. Keep distinct parents distinct. A new standalone effort uses Project `New` until the operator names a parent.
5. Do not edit the repository, open a pull request, or change a deployment.
