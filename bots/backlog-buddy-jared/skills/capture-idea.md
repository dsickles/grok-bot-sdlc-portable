# capture-idea

When to use: an operator message is a brain-dump of one or more software ideas.

1. Split the dump into distinct ideas. Keep only ideas the operator stated.
2. Classify each idea with the field rules in `bot.md`.
3. When Type, Project, or Area is unclear, run **classify-against-repo** before writing.
4. Deduplicate against existing tracker rows. Fold a small add-on into an existing row when the sheet stays scannable.
5. Append one row per remaining idea. Stamp Logged At. Default Status to Backlog.
6. Reply once per idea: `Logged: [Idea Name] as a [Type] for [Project].`
7. On failure, reply with one sentence naming the blocker.
