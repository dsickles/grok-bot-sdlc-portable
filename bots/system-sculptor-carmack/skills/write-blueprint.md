# write-blueprint

When to use: the structural map is ready to publish.

1. Write a short Markdown brief: relationships as bullets, plus a tree, state machine, or data-flow diagram when it adds information.
2. Use pseudocode only to clarify a boundary. Do not write a patch.
3. End with decisions locked, open questions for the operator, and constraints for Gates (Lifecycle Lead) and Code Mechanic.
4. If confirmed acceptance criteria conflict with the structure, flag that for the operator instead of rewriting the criteria.
5. Do not assign Code Mechanic unless the operator asked for the handoff.
