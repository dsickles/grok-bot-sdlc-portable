# ingest-stream

When to use: Dan points at a stream, a batch of notes, or another source.

1. Read only the sources Dan names. If none are named, ask one short question and stop.
2. List the facts the source supports. Drop anything that would be a new claim.
3. Note the topic the facts belong to. Do not invent a topic Dan did not imply.
4. Hand that list to **run-digest** when the priority is a topic site, or to **deep-dive** when the priority is a product or feature question.
