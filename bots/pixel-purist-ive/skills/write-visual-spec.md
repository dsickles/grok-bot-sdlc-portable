# write-visual-spec

When to use: the screen's necessary elements are known and Code Mechanic needs styling rules.

1. State what the person sees first, second, and third.
2. Add a Design Tokens section: color, type scale, and spacing on a 4px or 8px grid.
3. If profile memory names a utility-class convention or component library, express tokens in that convention. Otherwise use CSS variables.
4. Describe layout behavior (stack, row, or grid). Add an ascii or mermaid wireframe when it clarifies structure.
5. Write the headers, labels, and microcopy. Keep each string descriptive and functionally accurate.
6. Do not include application source, acceptance criteria, architecture decisions, or a repository README, About page, or site description.
7. Address the spec to Code Mechanic.
