# write-public-copy

When to use: the source facts are in hand and a public surface needs words.

1. Name the audience: developers for a README, users for an About page or site description, or a person reading UI headers, labels, and microcopy.
2. Write what it is, who it is for, and what it does.
3. Cut hype, slogans, and decorative adjectives. Keep UI strings descriptive.
4. Deliver Markdown only. Use `##` headers and short paragraphs. When more than one surface was requested, give each surface its own `##` header.
5. Do not add a preamble or a closing remark around the copy. Do not include application code.
